# 課題0506 AIコードレビュー

次の仕様のプログラムを，AIに書かせたという設定のコードが `main.c` にある．**このコードには誤りが複数ある．**

> 入力された double の数 r が **0 より大きい** とき，`r × r × 22.0` を **小数点以下2桁** で表示する．そうでない(0以下)ときは「NG」と表示する．

## 課題
1. `main.c` を直して仕様どおりに動くようにせよ．**入力と計算には `double` を使う**(`float` は不可)．`scanf` の書式は `%lf` を使う．
2. 元のコードの誤りを再現する入力を `bugs.txt` に1行1つ書け(書き方は課題0503と同じ)．
   - 3つ以上，**かつ** 次の3種類の誤りをすべて見つけること:
     「**0** を入力したとき」「**整数** の正の値を入力したとき」「**小数** の正の値を入力したとき」の3つで，元のコードと正しいコードの出力が食い違う．

ヒント: 型(`int` と `double`)，条件(`>` と `>=`)，定数(円周率の代わりに指示された数)のそれぞれを見直す．

## 提出するファイル
- `main.c`
- `bugs.txt`
- `ai_log.txt`
